

## Quick Start

### Installation

```bash
git clone https://github.com/yanxian-ll/evaluate_forward_models --depth 1
cd evaluate_forward_models

# Create and activate conda environment
conda create -n mapanything python=3.12 -y
conda activate mapanything

# ours
conda install -y -c conda-forge git ninja cmake
pip install -U pip setuptools wheel packaging psutil ninja
pip install torch==2.5.0 torchvision==0.20.0 torchaudio==2.5.0 --index-url https://download.pytorch.org/whl/cu121
pip install torch-scatter==2.1.2 -f https://data.pyg.org/whl/torch-2.5.0+cu121.html
# pip install flash-attn==2.7.3 --no-build-isolation

pip install -U psutil packaging ninja wheel setuptools
pip install --no-cache-dir --index-url https://download.pytorch.org/whl/cu121   "xformers==0.0.28.post2"

# Optional: Install torch, torchvision & torchaudio specific to your system
# Install evaluate_forward_models
pip install -e .
pip install -e . --no-deps

# For all optional dependencies
# This includes external model support (VGGT, DUSt3R, MASt3R, MUSt3R, Pi3-X, DA3, etc.)
# See "Running External Models" section for more details
# See pyproject.toml for more details on installed packages
pip install -e ".[all]"
pip install -e ".[depth-anything-3]"

python -m pip install -e ".[mast3r]" --no-build-isolation   -i https://pypi.tuna.tsinghua.edu.cn/simple   --trusted-host pypi.tuna.tsinghua.edu.cn

pre-commit install
```

### VSCode Rerun Viewer for `.rrd`

If the VSCode Rerun plugin can open `Rerun: Open Viewer` but fails to open an
`.rrd` file with an error like:

```text
Rerun Viewer: rerun process exited unexpectedly (code=2, signal=null)
```

check which extension is opening the file and which `rerun` binary it uses.
This repo's `mapanything` conda env may use `rerun-sdk==0.24.1`, but some
VSCode Rerun plugins start `.rrd` files with newer CLI flags such as
`--cors-allow-origin`. Those flags require a newer `rerun` CLI, and `.rrd`
files generated by newer scripts may also be 0.34.x recordings.

Recommended setup: keep the project conda env unchanged, and create a dedicated
Rerun CLI just for the VSCode plugin:

```bash
cd /opt/data/private/code/map-anything
python -m venv .venv-rerun-vscode
.venv-rerun-vscode/bin/python -m pip install "rerun-sdk==0.34.1"
.venv-rerun-vscode/bin/rerun --version
```

Then configure the workspace setting:

```json
{
    "python-envs.defaultEnvManager": "ms-python.python:conda",
    "python-envs.defaultPackageManager": "ms-python.python:conda",
    "rerun.rerunPath": "/opt/data/private/code/map-anything/.venv-rerun-vscode/bin/rerun"
}

```

In VSCode, run:

```text
Developer: Reload Window
```

If multiple Rerun extensions are installed, keep `ldenninger.rerun-vscode`
enabled and disable other Rerun viewer extensions first. The `rerun.rerunPath`
setting is used by `ldenninger.rerun-vscode`.

Useful checks:

```bash
rerun rrd verify path/to/file.rrd
.venv-rerun-vscode/bin/rerun --serve-grpc path/to/file.rrd --port 22350 --cors-allow-origin '*'
```

The second command should keep running. If it exits immediately with code 2,
the plugin is still using an incompatible `rerun` CLI.
